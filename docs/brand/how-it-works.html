What happens when you open a profile

The Work profile, from Spotlight, the Finder or claude-switch. Every way in takes the same route.

1Open

Claude (Work)

  • The launcher in /Applications hands off to claude-switch
  • Without claude-switch, it opens the stock app on Work's data
→
2claude-switch

Focus or prepare

  • Running already? Its window comes forward
  • Otherwise the clone is checked: moved forward if Claude.app is newer, never while in use
→
3Signed clone

Claude (Work).app

  • APFS clone of Claude.app, near-zero disk
  • Anthropic's signature intact: same CDHash, Gatekeeper accepts it
  • Finder icon with Work's badge
→
4Running as Work

Its own account

  • --user-data-dir → Work's gui-data
  • CLAUDE_CONFIG_DIR → Work's cli-config, shared with claude-work
  • Usage and sessions read the same paths as before
Reopened by an update or the Dock? macOS starts the clone without Work's arguments. The clone watch quits it within 20 seconds and opens Work again, or asks first if it has been running for a while.
Claude Desktop updated? Nothing to update here. Claude's version, signature and icon are read from the installed app every time, and clones catch up on their next launch.
